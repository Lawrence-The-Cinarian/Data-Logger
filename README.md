# Data-Logger

A basic program for inputing data, saving and outputing data. it consists of pointers, file handling, typedefs a d structs as well macros which lead to the introduction of header file 

# Clone to termux or linux environment

```
git clone https://github.com/Lawrence-The-Cinarian/Data-Logger
```

```
cd Data-Logger/src
```

Run it by entering 
```
make main
./main
```
if it doesn't work, then try 
```
gcc {main,datal}.c -main
./main
```
